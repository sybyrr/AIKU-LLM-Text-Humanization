# P3b — MASH 트랙 AI pair 생성 프롬프트 (확정본)

인간 초록 → AI 재서술문을 만드는 프롬프트입니다. 파일럿에서 프롬프트 5종 × 모델 2종을
카피킬러 500건으로 비교해 이걸 채택했습니다. 근거: [notes/43](../notes/43-MASH-파일럿-Stage0.md)

기존 [prompt_v3](kci_humanization_dataset_v0/prompt_v3.txt)에서 **"문장 단위로 대응시켜 재서술하라"는 요구를 뺀 것**이
핵심 변경입니다. 이 요구가 원문 복사를 유도했고, 많이 베낀 글일수록 탐지기가 **인간이 썼다고**
판정해서 오히려 성공률을 떨어뜨리고 있었습니다.

---

## 시스템 프롬프트

```
당신은 학술 문장을 다듬는 전문 국어 편집자입니다.
```

## 사용자 프롬프트

`{text}` 자리에 인간 초록 원문을 그대로 넣습니다.

```
다음 한국어 글을 같은 내용, 다른 문장으로 다시 쓰세요.
- 원문의 문장을 그대로 옮기지 말고, 어휘와 문장 구조를 새로 짜세요. 문장을 합치거나 나누어도 좋습니다.
- 사실은 하나도 바꾸지 마세요: 숫자·연도·비율·단위·통계값, 고유명사와 전문 용어, 증가/감소와 유의/비유의 같은 방향, 연구의 목적·방법·결과·결론을 모두 보존하세요.
- 요약하지 말고 분량을 원문의 90~110%로 유지하세요.
다시 쓴 글만 출력하세요 — 설명이나 제목, 마크다운 서식은 쓰지 마세요.

{text}
```

## 생성 설정

| 항목 | 값 |
| --- | --- |
| 모델 | **Qwen3-8B** (GGUF Q4_K_M, llama.cpp 서버) |
| temperature | **0.8** (0.0과 비교 후 확정 — 아래 참조) |
| seed | 42 |
| max_tokens | 원문 글자수 × 0.8 |
| 사고 모드(thinking) | **끔** (`--no-think`) |
| 동시 슬롯 | 4 |

> EXAONE-3.5-7.8B는 탈락했습니다. 초록 산문을 번호 목록으로 재구조화해버려서
> (50건 중 31건) 장르 자체가 깨집니다. Qwen3-8B는 150건 중 0건이었습니다.

**temperature는 0.8입니다 (0.0 아님).** 러셀 트랙은 0.0이지만 이 트랙은 다릅니다.
같은 원문 50편에 두 설정을 돌려 비교한 결과, **temperature 0.0이 원문을 더 많이 베낍니다** —
50편 중 37편(74%)에서 겹침이 늘었고 평균 +3.0%p였습니다(16.4% → 19.4%). 그리디 디코딩이
원문 표현에 더 붙기 때문입니다. 우리 파이프라인에서는 **덜 베낀 글일수록 탐지기가 AI로 잡으므로**
복사가 적은 0.8이 유리합니다. 길이와 깨짐률은 두 설정이 같았습니다.

실행:

```bash
python3 scripts/generate.py \
  --in <프롬프트.jsonl> --out <출력.jsonl> \
  --url http://127.0.0.1:8081/v1/chat/completions \
  --model qwen3-8b --no-think
```

## 생성 후 판정

만들어진 쌍은 **세 조건을 모두** 통과해야 데이터셋에 들어갑니다 (앞의 둘이 MASH 논문 기준).

1. 인간 원문이 탐지기에서 **인간**으로 판정
2. AI 재서술문이 탐지기에서 **AI**로 판정
3. 글이 **깨지지 않았을 것**

3번은 의미가 달라졌는지가 아니라 **생성 자체가 실패했는지**만 봅니다 —
빈 출력·원문의 50% 미만·200% 초과·마크다운·도입 문구·같은 구절 반복·문장 중간 잘림·
한글 비율 30% 미만·제어토큰 잔재. 실측 깨짐률은 250건 중 2건(0.8%)입니다.

수치나 고유명사 보존은 **검사만 하고 기록해두되, 탈락 기준으로 쓰지 않습니다.**
논문에도 그런 필터는 없습니다.
