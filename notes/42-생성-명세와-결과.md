> 구현: `../data/`

파일럿 규모: 인간 원문 **10편** × 조건 3개 × 모델 3종 = **90편**.
1차(A/B/C)는 완료, 2차(A/E/C)는 진행 중이며 조건 B가 2차에서 E로 교체됐습니다.

## 1. 인간 원문

파일럿은 HF 미러 `Saxo/ko-news-corpus-{1,7,8}` 사용.

**추출 조건** — `data/extract_russell_pool.sql`

```sql
date < 20221101                                  -- ChatGPT 출시 이전
topic IN ('정치','경제','사회','IT/과학','문화')  -- 스포츠·연예·생활·미용건강 제외
length(body) BETWEEN 1500 AND 2500
n_para >= 8
title NOT LIKE '%.'  AND  length(title) BETWEEN 10 AND 60
```

후보 20,739편 → 토픽별 20편 × 매체 라운드로빈 = **100편**.
파일럿은 그중 토픽별 2편씩 **10편**(`pilot_base.jsonl`).

| | 값 |
| --- | --- |
| 평균 본문 | 1,826자 |
| 평균 문단 | 12.7 |
| 매체 | 9곳 (국민일보·노컷뉴스·경향신문·내일신문·세계일보·서울신문·헤럴드경제·뉴스핌·스포츠서울) |
| 토픽 | 정치·경제·사회·IT/과학·문화 각 2편 |

기사 복원은 `doc_id`로 묶고 `para_idx >= 2`를 **개행 2개로 join**. `para_idx = 1`이 제목입니다.
상세는 [40-코퍼스-구조-용어](40-코퍼스-구조-용어.md).

### 조건 E — 명사 목록 25개

```bash

```

조건 간 차이는 n=30에서 노이즈 범위이고, **세 조건 모두 인간과의 격차가 그대로 남습니다.**
명사 목록으로 `김소영·금융위원회·당정간담회`를 다 알려줘도 모델은 여전히 총론으로 시작합니다.

**해석**: 인간 리드와의 차이는 *정보 부족*이 아니라 *서술 관습*의 문제입니다. 컨텍스트 조건을
늘려서 좁힐 수 있는 격차가 아니며, 개입(프롬프트 지시·샘플러·학습) 쪽에서 다뤄야 합니다.
역으로 이는 **조건을 늘릴 실익이 적다**는 뜻이기도 해서, 본 실행에서 조건 수를 줄일 근거가 됩니다.

## 6-D. Fast-DetectGPT

`data/detect_scores.jsonl` · `detect_fastdetectgpt.py` · 스코어러 `LGAI-EXAONE/EXAONE-4.0-1.2B`

[평가기준](20-평가기준.md) 15번 줄이 요구하는 "likelihood 계열" 탐지기입니다. 학습 없이
단일 forward pass로 조건부 확률 곡률을 계산합니다.

    d(x) = (Σ log p(x) - Σ mu) / sqrt(Σ var)
      mu  = E_{x~p}[log p(x)],  var = Var_{x~p}[log p(x)]   위치별 해석적 계산

스코어러 선택 근거 — 한국어 모델이어야 인간 글에 제대로 확률을 매기고, 생성에 쓰지 않은
모델이라 self-detection 편향이 없습니다.

로직 사전 검증(Qwen3-0.6B, CPU, 512토큰 절단):

| 구분 | 곡률 점수 |
| --- | --- |
| 인간 | −4.561 / −5.402 / −4.674 |
| AI (EXAONE-33B) | −3.356 / −0.166 / −0.303 |

두 집단이 겹치지 않고 **AI가 일관되게 높습니다**(방향 정상).

### 구현 버그 — 합이 아니라 평균

처음 구현은 곡률을 **합**으로 계산했습니다. 그러면 분자는 토큰 수 n, 분모는 √n 에 비례해
점수가 √n 만큼 부풀고, 길이가 다른 모델끼리 비교가 불가능해집니다.

    잘못  (actual.sum() - mu.sum()) / var.sum().sqrt()      점수 ∝ √n
    수정  (actual.mean() - mu.mean()) / var.mean().sqrt()   길이 무관

첫 실행 결과는 **모델 순위가 토큰 수 순위와 완전히 일치**했고(AI 길이-점수 상관 0.681),
그대로 믿었다면 "gemma 92%, Qwen3-8B 14%" 를 보고하며 "짧고 건조한 글이 탐지를 회피한다"는
서사까지 붙일 수 있었습니다. 실제로는 길이가 만든 인공물이었습니다.
사전 검증을 512토큰으로 잘라서 했기 때문에 이 편향이 드러나지 않았습니다.
버그 버전은 `detect_scores_buggy.jsonl` 로 남겨 두었습니다.

수정 후 상관은 0.681 → **0.493** 으로 줄었으나 완전히 사라지지는 않았습니다.

`has_markdown`·`had_think`·`reason_char`는 지시 이행과 사고모드 누출을 사후에 집계하려고
