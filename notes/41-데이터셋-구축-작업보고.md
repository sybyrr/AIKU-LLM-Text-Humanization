## 1. 데이터

**국립국어원 신문 말뭉치 2023**(2022년 생산 기사)을 씁니다. 파일럿은 HF 미러
`Saxo/ko-news-corpus-1~8`로 진행했고, 정식 승인본을 받으면 경로만 바꿔 재실행합니다.

### 탈락시킨 후보

| 후보 | 사유 |
| --- | --- |
| HF `naver-news-summarization-ko` | 쉼표·따옴표가 전처리에서 제거됨. 문체 연구에 치명적 |
| 빅카인즈 | 본문 전문 미제공. 메타데이터·엔티티 CSV만, 전문은 유료 구매 |
| XL-Sum 한국어 | BBC 코리아 단일 매체, 번역체 혼입 |
| `acul3/KoPI-CC_News` | 이름만 Korean, 실제 내용은 인도네시아어 |

### 구조 검증 — 컬럼명이 내용과 어긋남

그대로 쓰면 파이프라인이 조용히 망가집니다. shard1(103,464기사) 확인값. 상세는
[40-코퍼스-구조-용어](40-코퍼스-구조-용어.md).

- **행 단위는 문장이 아니라 문단** — 컬럼명은 `sentence`지만 본문 행의 **29.1%**가 문장 2개 이상.
  이어붙일 때 개행 2개로 join 해야 원문 문단 구조가 살아납니다.
- **`title` 컬럼은 기사 제목이 아님** — `노컷뉴스 2022년 기사` 같은 파일 제목.
  실제 제목은 `para_idx = 1` (마침표로 끝나는 비율 0.01%, 40자 미만 92.5%).
- **부제가 없음** — `para_idx = 2`는 98.5%가 `~다.`로 끝나는 76자 서술문. 리드 문단이지 부제가 아닙니다.
  러셀 프롬프트의 `Subtitle:` 자리를 채울 필드가 없습니다.

### 표본 추출

샤드 1·7·8에서 28만 편을 받아 필터링 — 발행일 `< 2022-11-01`, 토픽 5종,
본문 1,500~2,500자, 8문단 이상. 조건 통과 후보 **20,739편**에서 토픽별 20편씩
매체 라운드로빈으로 100편. `hash(doc_id)` 정렬이라 재실행해도 같은 표본이 나옵니다.

> **2022-11-01 컷오프는 ChatGPT 출시일입니다.** 이후 기사는 "인간 글" 라벨 자체가 오염될 수 있습니다.
> 신문 말뭉치 2023(2022년 기사)이 오염 직전 마지막 안전 연도이고, 더 필요하면 2022판·2021판으로 갑니다.

## 2. 실행 환경

GPU가 **TITAN Xp 4장(각 12GB, sm_61)**. Pascal 세대라 최신 스택이 대부분 막힙니다.

| 항목 | 상태 | 대응 |
| --- | --- | --- |
| CUDA 13 | 불가 — Pascal 지원 제거 | torch cu126 빌드로 고정 |
| vLLM | 불가 — CC 7.0+ 요구 | llama.cpp 소스 빌드 |
| Flash Attention | 불가 — Ampere 이상 | sdpa |
| bitsandbytes NF4 | 느림 — fp16 대비 7.6배 | 미사용 |
| GGUF Q4 (llama.cpp) | 정상 | **채택** |

컨테이너에 컴파일러가 없고 sudo도 없어 micromamba로 gcc·cmake·nvcc를 유저 권한에 설치한 뒤
`-DCMAKE_CUDA_ARCHITECTURES=61`로 빌드했습니다.

### 양자화 방식이 판단을 뒤집음

bitsandbytes만 재고 "32B는 불가"로 결론냈다가, llama.cpp 실측에서 뒤집혔습니다.
llama.cpp는 Pascal용 DP4A 정수 커널을 직접 구현해 두었습니다.

| 33B 실행 방식 | 생성 속도 | 300편 소요 |
| --- | --- | --- |
| bitsandbytes NF4 (추정) | 0.6 t/s | 156시간 |
| llama.cpp Q4_K_M 단일 | 14.2 t/s | 7.1시간 |
| llama.cpp Q4_K_M · 슬롯 4 | **32.1 t/s** | **3.1시간** |

18.66 GiB라 카드 2장에 들어가고, 4장으로 늘려도 단일 스트림 속도는 같습니다(파이프라인 분할).
인스턴스를 2개 띄우면 처리량이 두 배가 됩니다.

## 3. 프롬프트 — 원논문 대비 조정

러셀 원 프롬프트는 `{섹션} · {목표 단어수} · Title · Subtitle` 네 슬롯입니다.
저장소 실물 확인 결과 `publication`과 `name_list`는 선택 인자였고, 부제는 편집자가 쓴
**리드 문장의 압축본**이었습니다(부제/기사 비율 실측 2.9%).

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| 프롬프트 언어 | 한국어 | 위협 모델(학생이 한국어로 지시)과 일치. 조건 안에서 고정되므로 실험 내부 영향 없음 |
| 발행일 | 연월일 제공 | 2022년 기사를 2026년 모델로 생성하므로 시점 오류가 문체 아닌 단서를 만듦. **지식 사용 자체는 못 막음** |
| 섹션 | 대분류만 | `original_topic`은 다중값 87.7%, `topic`과 대분류 불일치 56.9%. 태그가 기사 내용과 어긋남 |
| "전문가 인용 포함" | **제거** | 가짜 전문가 생성을 유도해 문체 아닌 단서를 만듦. "간결하게"는 유지 |
| 출력 형식 | 마크다운 금지 + 제목 재출력 금지 | 기사는 마크다운 형식이 아니라 형식 위반이 문체 단서로 오인됨. 원논문에 없는 조정 |
| 목표 분량 | 100자 단위 반올림, 재생성 없음 | 편차는 사후 측정 |
| 기자 시점 | **추가** | `당신은 {날짜}자 {매체} {섹션}의 기자입니다`. 러셀 evade 프롬프트와 같은 형태 |

`original_topic` 실패 사례: 울진(경북) 산불 기사에 `지역>경남, 지역>강원, 지역>대전`,
대구 코로나 기사에 `지역>광주`. 주면 틀린 정보를 주입하는 셈입니다.

### 기자 시점 한 줄의 효과

기존 `다음은 …기사의 제목입니다`는 모델을 **관찰자 위치**에 세워 회고적 서술을 유도했습니다.
EXAONE-33B 10편 비교:

| 지표 | 기존 | 기자 시점 | 인간 원문 |
| --- | --- | --- | --- |
| 첫 문장이 인용동사로 끝 | 0/10 | **3/10** | 3/10 |
| 길이 달성률 | 80% | **91%** | — |
| 첫 문장 고유명사 시작 | 3/10 | 4/10 | 8/10 |
| 발행 연월 본문 노출 | 4/10 | 3/10 | 0/10 |

```
인간      김소영 금융위원회 부위원장은 13일 일명 '루나 사태'로 인한 가상자산 시장의
          문제점을 언급하며 해결책 마련 필요성을 강조했다.

기존      2022년 6월 루나 토큰의 급락은 국내외 가상자산 시장에 커다란 충격을 주었다.
          … 루나는 스테이블코인 테라USD(UST)와 함께 운영되던 알트코인으로,

기자시점  금융위원회와 금융감독원이 최근 루나·테라USD 사태로 인한 가상자산 시장의
          혼란을 진단하고, 시장의 건전성 회복을 위해 자정작용이 시급하다고 강조했다.
```

주어가 사건에서 행위자로 옮겨갔고 `2022년 6월`이 `최근`·`지난 5월 중순`으로 바뀌었습니다.
첫 문장 형식을 지정하지 **않았는데도** 따라온 결과입니다.

### 남긴 결함 — 의도적

기자 시점을 주자 일부가 `2022년 6월 13일, 금융위원회와…`처럼 **날짜를 문장 앞에 박는 패턴**을
보였습니다(인간 0/10). 이는 러셀 evade 지침이 정확히 겨냥하는 항목입니다 —
*"Avoid formulaic introductions that elaborate on scene-setting or time."*

러셀도 이 현상을 겪었고 실험 5(humanization)에서만 지시로 막았습니다.
**베이스라인에서 지우면 이미 회피 처리된 조건이 되어 개입 효과를 잴 수 없습니다.** 지표로 기록하고 둡니다.

### 쌓지 않기로 한 지시

발행일 명시 금지 · 첫 문장 형식 지정 · 배경 설명 금지 · 문단 길이 지정을 검토했으나 모두 뺐습니다.
한국 기사는 `13일`·`지난달`을 상시 쓰므로 날짜 금지는 역효과이고, 첫 문장 형식 지정은 구조를
하나로 고정하며 인간 원문의 형식을 프롬프트로 알려주는 셈입니다. 문단 길이는 RQ가 측정하려는 종속변수입니다.

## 4. 조건 설계

"프롬프트에 원문 정보를 얼마나 주느냐"가 핵심 변수입니다. 러셀 실측 2.9%(부제/기사)가 1배 기준.

| 조건 | 제목 외 제공물 | 분량 | 기사 대비 | 러셀 대비 | 인간 산문 |
| --- | --- | --- | --- | --- | --- |
| **A** | 없음 | 34자 | 1.9% | 0.7배 | 없음 |
| **C** | 합성 요약 1문장 | 70자 | 3.8% | 1.3배 | 없음 |
| **E** | 명사 목록 25개 | 117자 | 6.4% | 2.3배 | 구조적으로 불가 |
| ~~B~~ | ~~도입부 2문장~~ | 152자 | 8.5% | 2.9배 | **최대 100% 복사** |

### 조건 B는 왜 폐기됐나

B만 프롬프트에 인간 산문이 들어갑니다. A·C의 겹침이 자연 발생 수준이므로 B의 초과분이 실제 복제량입니다.

| 조건 / 모델 | 최장 공통 부분문자열 | 12자 N그램 겹침 |
| --- | --- | --- |
| A (제목만) | 9.4자 | 0.5% |
| C (요약) | 10.3자 | 1.2% |
| **B 전체** | 28.2자 | 20.4% |
| B · EXAONE-33B | 18.7자 | 11.2% |
| B · EXAONE-7.8B | 18.3자 | 9.0% |
| B · **Qwen3-14B** | **47.5자** (최악 132자) | **41.0%** (최악 100%) |

Qwen3-14B는 10편 중 2편에서 **도입부 전체를 한 글자도 바꾸지 않고 옮겼습니다.**
평가자가 읽을 AI 글에 인간 문장이 통째로 들어가면, 낮아진 탐지율이 "AI가 사람처럼 썼다"인지
"사람 문장을 붙여넣었다"인지 구분되지 않습니다.

### 조건 E — 명사 목록

Kiwi로 명사를 뽑아 등장 순서 25개를 줍니다. 목록은 문장이 아니라 복제 자체가 불가능하면서
정보량은 B와 비슷합니다.

```
핵심어: 김소영, 금융위원회, 부위원장, 일명, 루나, 사태, 가상자산, 시장, 문제점,
        언급, 해결책, 마련, 필요, 강조, 이날, 국민, 정책위원회,
        가상자산특별위원회, 공동, 주최, 공정, 회복, 투자자, 보호, 당정간담회
```

- 고유명사(NNP)만 뽑으면 7개(29자)뿐이고 `금융위원회` 같은 핵심 기관명이 NNG로 분류돼 빠집니다.
  그래서 NNP+NNG를 씁니다.
- Kiwi가 쪼갠 복합어(`금융/위원회`)는 원문 인접 여부로 다시 합칩니다.
- 빈도순은 `김·이·때` 같은 껍데기가 올라와 **등장 순서**를 택했습니다. 한국 기사는 리드에
  육하원칙이 몰려 있어 등장 순서가 핵심어를 앞에 놓습니다.

### 조건 C — 요약 합성과 검사

코퍼스에 부제가 없어 Qwen3-14B로 한 문장 요약을 합성해 모든 모델이 공유합니다.
**요약기를 EXAONE이 아닌 Qwen으로 둔 이유**: 생성 모델 3종 중 EXAONE 계열이 2개라
EXAONE으로 요약하면 3분의 2가 자기 계열 요약을 받게 됩니다.

검사 두 가지 — 원문 문장을 그대로 옮겼는지(최장 공통 부분문자열 25자 이하),
원문에 없는 숫자가 들어갔는지. **10/10 통과**, 평균 70자, 최대 겹침 25자.

| API 생성 | 폐기 | 조건 C·E는 기사 전문을 모델에 보내야 하는데 **모두의 말뭉치는 재배포 금지**라 상용 API 전송은 약정 위반 소지가 있습니다. 로컬이면 발생하지 않습니다 |

## 6. 파일럿 결과

1차(조건 A/B/C, 기존 프롬프트) 90편 기준.

| 모델 | 평균 자수 | 길이 달성률 | 마크다운 누출 | 편당 |
| --- | --- | --- | --- | --- |
| EXAONE-4.5-33B | 1,467 | 80% | 0 / 30 | 67.9초 |
| Qwen3-14B | 1,259 | 68% | 0 / 30 | 49.5초 |
| EXAONE-3.5-7.8B | 1,787 | 98% | **30 / 30** | 25.6초 |

소형 모델이 가장 빠르고 분량도 정확하지만 **마크다운 금지를 30건 전부 무시했습니다.**
지시 이행 능력의 체급 차이가 그대로 드러납니다. 평가자가 볼드·불릿을 보면 문체를 읽기 전에
판정해 버리므로 실험에 직접 영향을 줍니다.

### 문단 구조 — 자동 측정 가능한 AI 특징

한국 신문은 문단을 짧게 끊습니다. 생성물은 그렇지 않습니다.

| 대상 | 문단 수 | 문단당 문장 | 문단 길이 |
| --- | --- | --- | --- |
| **인간 원문** | 12.9 | 2.14 | 155자 |
| EXAONE-33B | 7.0 | 3.09 | 210자 |
| Qwen3-14B | 6.1 | 3.02 | 206자 |
| EXAONE-7.8B | 18.0 | 1.89 | 100자 |

대형 모델 둘은 **문단 수가 절반, 문단 길이가 1.4배**입니다. 7.8B의 18문단은 마크다운 불릿이
줄로 세어진 착시입니다. [RQ](11-RQ.md)가 찾던 "AI스러운 특징"에 해당하면서
자동 측정이 가능해 지표로서 가치가 큽니다.

## 7. 파일럿이 잡아낸 버그

| 버그 | 원인 | 조치 |
| --- | --- | --- |
| 90편 전부 빈 문자열이 될 뻔 | EXAONE-4.5-33B가 **추론 모델**. `content`가 비고 `reasoning_content`로만 14,239자(영어) | `enable_thinking:false` 적용, **빈 출력을 에러로 승격** |
| 토큰 상한 과다 | 한국어 실측 **2.87자/토큰**인데 `max_tokens`를 목표 글자수의 1.6배로 잡음 | 0.8배로 조정 |
| 간헐적 HTTP 500 | llama.cpp chat 파서의 `peg-native format` 오류. 파라미터와 무관하게 샘플링 결과에 따라 발생(90건 중 1건) | 시드를 바꿔 3회 재시도 |

세 버그 모두 **조용히 실패하는 종류**였습니다. 빈 문자열, 잘린 텍스트, 누락된 한 건 —
90편을 그대로 뽑았다면 검수 단계에서야 발견됐을 것입니다. 파일럿을 10편으로 잡은 판단이 유효했습니다.

## 8. 남은 일

- **2차 파일럿 완료** — 조건 A/E/C × 모델 3종. 관심 지표는 E가 A보다 인간 리드 형식에
  가까워지는지(첫 문장 고유명사 시작 4/10 → ?)
- **모델 확정** — 마크다운 누출을 감안하면 EXAONE-7.8B는 후처리 없이 쓰기 어렵습니다.
  Qwen3-32B Q4(약 20GB)가 있어 EXAONE-33B의 직접 대조군으로 추가 가능
- **본 실행** — 100편 × 조건 3 × 모델. 33B 기준 조건당 3시간, 인스턴스 2개면 절반
- **정식 승인본 검증** — 원본 JSON은 제목을 메타 필드에 둘 가능성이 있어
  `para_idx = 1 = 제목` 가정을 다시 확인해야 합니다 ([40번 문서](40-코퍼스-구조-용어.md) 6절)
- **의미 정합 측정** — 개체명·수치 겹침을 주 지표로, 임베딩(BGE-m3)은 하한 스크리닝.
  인간–인간 같은 사건 쌍 13,829개가 눈금
- **평가자 설명 코딩** — "내용·사실 근거" vs "문체 근거" 분리.
  탐지가 문체 때문인지 재는 유일한 직접 수단 ([러셀 평가방식](21-러셀-ACL2025-평가방식.md) 3절)

### 아직 답이 없는 것

**모델이 원문을 외우고 있을 가능성.** 2022년 기사는 웹에 공개돼 있고 신문 말뭉치도 공개
코퍼스입니다. 발행일을 주면 인출이 더 쉬워집니다. 프롬프트로는 막을 수 없고 사후 측정만
가능합니다 — 생성물과 원문의 5-gram 이상 일치 구간을 재고, 인간–인간 쌍의 중복률 분포와
비교해 암기 재현을 걸러내야 합니다.
