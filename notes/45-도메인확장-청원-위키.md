# 45 · 도메인 확장 — 국민청원 · 위키피디아

> 신문 트랙 humanizer 파이프라인을 두 신규 도메인(국민청원·위키피디아)에 그대로 적용해 일반화 검증.
> 파일럿 규모(도메인당 생성 2,500). 생성기 1종(qwen3-8b). 작성 2026-08-26.

## 0. 결론
- **방법이 도메인을 넘어 일반화됨** — 청원은 news급으로 깨끗, 위키는 백과 리스트 문체 탓에 부분 붕괴.
- **DPO(DPOP λ5)는 3도메인 모두 SFT보다 소폭 회피 개선, 붕괴 없이.** 변화폭은 hard-neg 수에 비례(위키>신문>청원).
- **독립 탐지기(SCRN) 전이**: 신문은 강하게 전이(SFT/DPO를 0.16/0.10로 사람 판정), 청원 부분 전이, 위키는 전이 실패(news-SCRN이 위키 인간글도 0.58로 오판).

## 1. 데이터 (pre-ChatGPT 필수)
- **청원**: HF `dev7halo/bluehouse-national-petition` (청원시스템 2017~2022.5 종료 = pre-ChatGPT). `청원내용` 필드, 765~3000자 필터 → `dataset/petition_track/human_pool.jsonl` (8,000편, 중앙 1,421자).
- **위키**: HF `wikimedia/wikipedia` `20231101.ko`. text 765~2500자, 각주 꼬리 제거 → `dataset/wiki_track/human_pool.jsonl` (8,000편, 중앙 1,336자). ※덤프는 2023이나 본문 대부분 pre-2022(주의점).
- **탈락**: AIHub 에세이(`/shared/mash/aihub_essays.jsonl`)는 2024~25 수집 + LLM 오염 18%로 **사용불가**(mash/aihub_verdict.md).

## 2. 파이프라인 (도메인당)
1. **AI 생성**: rewrite 프롬프트(`prompts/mash/rewrite_ko.user.txt`, 기사→글) + qwen3-8b(llama-server, --no-think). 2,500편.
2. **detector 학습 + 게이팅**: `news_gate_frozen.py --det-n 750 --tau 0.5`. gate: `d_human<0.5 AND d_ai>=0.5`. → `{dom}_roberta_D` + `dpair.jsonl`.
3. **SFT**: `stage2_sft.py --epochs 3 --bs 8 --lam 0.5` → `models/{dom}_sft`.
4. **DPO**: `stage3_build_dpo.py --n-sample 4` → `stage3_dpo.py --dpop --dpop-lambda 5.0 --length-norm --beta 2.0 --epochs 1` → `models/{dom}_dpo`.
5. **평가**: SFT vs DPO 4단 리뷰(`make_dpo_review.py`), t-SNE+점수(`analyze_domain.py`).

## 3. 결과

### 게이팅 (flip = AI가 AI로 잡힘, 통과 = 학습쌍)
| 도메인 | flip율 | 통과쌍 | DPO hard-neg |
|---|---|---|---|
| 청원 | 78% | 1,425 | ~280 |
| 위키 | 73% | 1,197 | 594 |

### SFT 리뷰 (plain beam4, 30샘플)
| 도메인 | len비 | rep3 | 붕괴율 |
|---|---|---|---|
| 청원 | 0.86 | 0.029 | **0%** |
| 위키 | 0.97 | 0.120 | **10%** |

### 탐지기 P(AI) — 낮을수록 사람 (n=80, plain beam4)
| 도메인 | roberta-D: H/x_ai/SFT/DPO | SCRN: H/x_ai/SFT/DPO |
|---|---|---|
| 신문 | 0.04 / 0.999 / 0.23 / **0.16** | 0.00 / 1.0 / 0.16 / **0.10** |
| 청원 | 0.20 / 0.80 / 0.55 / **0.50** | 0.14 / 0.89 / 0.67 / 0.63 |
| 위키 | 0.20 / 0.86 / 0.64 / **0.58** | 0.58 / 0.94 / 0.92 / 0.91 |
- SFT vs DPO 유사도: 신문 95% / 청원 98% / 위키 93% (DPO 변화폭 = hard-neg 비례).

## 4. Caveat
- **청원·위키 detector는 750개만 학습**이라 신문(20k)보다 약함(H/x_ai 0.20/0.80로 뭉툭). 회피 수치가 지저분한 건 도메인 문제가 아니라 **detector 약함**일 수 있음 — 공정비교엔 detector 확대 필요.
- 생성기 1종(qwen)이라 detector가 qwen-특정. 본 확대 시 3종(qwen/exaone/kanana).
- 위키: 백과 리스트("첫째/둘째") 구조가 붕괴·SCRN 전이실패의 원인.
