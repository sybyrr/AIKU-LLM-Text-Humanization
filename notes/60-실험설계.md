# 60. 실험 설계 (통합 정리)

> 2026-08-24 세션 정리. 붕괴 디버깅·D2·지표가 쌓이며 흐려진 전체 설계를 한 곳에 고정.
> 상위: [평가 기준](20-평가기준.md) · [MASH 제안](30-MASH-기반-제안.md) · [파이프라인 현황](50-파이프라인-현황.md)

## 0. 한 문장
**AI가 쓴 한국어 뉴스를 humanizer(StyleBART SFT+DPO+Stage4)로 다시 써서, 내용·품질을 유지한 채 black-box 탐지기가 "사람 글"로 오판하게 만들 수 있는가** — 나아가 학습에 안 쓴 탐지기까지 속이면(전이) 더 강한 주장.

## 1. 탐지기 역할 (혼란점 — 명확히)
- **black-box(메인)** = 내부/그래디언트 없이 **점수(score)만** 보고 낮추기. 우리는 D를 gate·DPO에서 점수로만 씀 → D는 이미 black-box 타깃.
- **black-box ≠ unseen.** D는 black-box이면서 seen. transfer는 별개 축.

| 탐지기 | 역할 | 상태 |
| --- | --- | --- |
| D (klue-roberta, 750편·2생성기) | **타깃**(gate+DPO보상+평가) | AUROC 0.9913 |
| **D2** (4,500·3생성기 qwen/exaone/kanana) | **새 타깃**(교체 예정) | 학습중 |
| SCRN (koelectra) | transfer(부차·일반화) | AUROC 0.9996 |
| Binoculars·FastDetect (zero-shot) | transfer | 한국어에 약함(x_ai도 65/94% 오판) |
| 카피킬러 | 원논문의 진짜 black-box | **API 없음** → D가 대역 |

## 2. 조건 × 지표 (최종 산출 = 이 표)
- **조건**: x_ai(baseline) / SFT / DPO / Stage4.
- **지표 3축**: ① 회피 = **TPR@FPR5%**(사람 p95 임계) ② 의미보존 = cos·BERTScore ③ 유창성·붕괴 = PPL·rep-n/collapse.
- **②③은 회피의 게이트** — 붕괴·의미파괴로 낮춘 회피는 무효("가짜 성공", 실측으로 겪음: cos·BERTScore는 꼬리루프 못 잡고 rep-n/collapse가 잡음).
- **평가셋 = clean20k `test` split held-out** (기존 transfer셋은 v2-test 기반이라 clean20k train과 116/150 누수 → 폐기, 모델 다 나오면 test에서 새로 시드).

## 3. 데이터 & 누수 감사 (검증 완료)
- clean20k: 국립국어원 신문 말뭉치 2022 → 추출(3,000+확장19,500+topup5,000) → 2생성기 → **frozen-D 게이트** → 정제(722 D누수 제거) → 20,343쌍(train16,266/dev2,033/test2,044).
- **겹침 = 0**: clean20k ∩ D학습(750) = 0, train ∩ test = 0. 오염본 `news_dpair_final.jsonl`(722 누수) **폐기·사용금지**.
- ⚠️ **old-D 선택편향**: clean20k는 old D 게이트로 걸러진 subset → SFT 학습분포가 old D 경계에 편향. **D2 타깃 시 재-게이트 필요**(SFT 로직은 detector 무관하나 데이터는 D가 고른 것).

## 4. 붕괴 진단 (결론)
- 원인: **fusion이 additive**(논문=concat) + **degenerate 베이스**(124M·3,055쌍). 디코딩은 `no_repeat_ngram=3`(붕괴0·garble) vs `repetition_penalty=1.2`(garble0·30~53%루프) **양극단**.
- 붕괴 양상 = 정상 프리픽스 뒤 salient 명사에 꽂히는 **꼬리 EOS 루프**(neural degeneration), 입력 무관.
- → **concat + clean20k**로 재검증 중(`news_sft_concat20k`, GPU0). ≈0%면 "우리 이탈 탓" 확정.

## 5. DPO 논문 대조 (Stage 3)
- **논문 = vanilla DPO**: reward `r=−C·D(y)`(C는 loss에 안 들어가는 이론장치), 표준 손실 Eq.8, **chosen=x_human**·**rejected=SFT샘플 중 D>τ**(hard-neg)·**ref=SFT**. 길이정규화·SFT앵커 **없음**. 하이퍼 lr5e-6·**5ep**·per-device bs2×**accum8=유효16**·β미명시·beam4. **페어 1회 고정·비iterative.** 품질저하는 **Stage4로 복원** 전제.
- **우리 = 공식 충실**(reward/손실/chosen/rejected/ref 동일). 이탈 두 개: **(a) 유효배치 4 vs 16**(accum 없음→노이지·불안정), **(b) SFT 베이스 붕괴성**.
- **정합성 버그 없음**: `seq_logprob` teacher-forcing 정렬 올바름.
- **처방 A(충실 우선)**: 건강한 concat SFT + `--accum`(유효16) + 5ep + **concat fuse 수정**(현재 additive 하드코딩→concat SFT면 크래시) + Stage4.
- **처방 B(논문 밖, plan B)**: β↑(0.3~0.5) / length-normalized logprob / chosen-NLL 앵커 — A로도 파국이면 얹음.

## 6. D2 (강한 탐지기, gate 교체 후보)
- 4,500 fresh(누수0) × 3생성기 라운드로빈 → klue-roberta. 현 D(750·2생성기)보다 5×데이터·+Kanana(신규계열).
- 순서: D2 완성 → **D vs D2 pair-flip율** 측정(재-게이트 영향 정량화) → 원시 풀 **D2 재-게이트** → SFT 재학습(warm-start) → **DPO(처방 A) against D2** → clean20k test 평가.

## 7. 결정된 것 / 열린 것
- **결정**: black-box 회피가 메인·transfer 부차 / D2로 타깃 교체 / 평가는 clean20k test held-out / DPO는 충실 재현 우선 / ②③을 회피의 게이트로.
- **열림**: CFG·방향증폭 확장 여부 / Stage4 실측(미탐색) / BERTScore 구현 / D2 gate 교체 최종 확정(pair-flip 보고 결정).
