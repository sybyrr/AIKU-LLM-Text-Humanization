## 0. 전체 흐름

```
① 인간 신문 기사 추출        (국립국어원 2022판 = 2021년 기사)
   │  800~1200자 · topic 5종 층화 · 인용 40% 이하
   ▼
② P3b 프롬프트로 재서술       2 arm: Qwen3-8B(ratio 1.6) + EXAONE-3.5-7.8B(ratio 1.2), temp 0.8
   │  (인간 원문 → AI 재서술문)
   ▼
③ 고정 D 게이트              detector-split 750기사로 RoBERTa 1회 학습 → 동결
   │  인간 원문 D<τ AND AI 재서술 D≥τ 인 쌍만 통과 = D_pair
   ▼
④ Stage 2 SFT               ko-BART, 이중경로(CR+ASR/HSR), L_recon+L_trans
   │  x_ai → x_human 스타일 변환 학습
   ▼
⑤ Stage 3 DPO               chosen=x_human, rejected=SFT 실패작(D>τ)
                            보상 = RoBERTa (게이트와 동일 탐지기)
```

**탐지기 D 는 전 과정 동일** — 게이트 / DPO 보상 / 평가 모두 같은 RoBERTa.

## 1. 탐지기 D (확정)

**klue/roberta-base 파인튜닝, 도메인별 학습.** 근거: DETECTOR_RESULTS.md
- 초록 도메인 F1 0.959 / 인간 오탐 8.2% (카피킬러급, 임베딩·표면특징 압도)
- **도메인 의존**: 초록 학습본을 신문에 쓰면 인간 오탐 44% → 신문으로 학습하면 17%
- ~~신문으로 RoBERTa 를 5-fold 학습~~ **(2026-08-16 오후 폐기 — 회의 지적으로 확인)**:
  5-fold 는 fold마다 다른 모델 5개가 채점하고 버려져, 이후 DPO 보상·최종 평가에 쓸
  단일 D 가 없다("전 과정 같은 D" 원칙과 모순). 또 pair 전체(test 포함)로 학습해
  최종 평가에 쓰면 test 누수가 된다.
- **확정: frozen D** — 기사 단위 detector-split(750편)의 인간 원문 + 2 arm 재서술로
  RoBERTa 1회 학습·동결(`/workspace/models/news_roberta_D`). 게이트·DPO 보상·평가에
  이 하나를 재사용. D 학습 기사는 pair 풀에서 제외라 누수 없음. 논문의 detector-train
  split(3:1:1:1) 구조와 동일.

## 3. Stage 2 SFT 구조 (원논문 이중경로)

```
x_ai → ko-BART 인코더 → CR (content representation)
  경로1: CR + ASR → fusion → 디코더 → x_ai 복원    L_recon (의미 보존)
  경로2: CR + HSR → fusion → 디코더 → x_human 생성  L_trans (문체 이식)
L_SFT = λ·L_recon + (1-λ)·L_trans,  λ=0.5 (원논문)
```

**구현 결정** (논문에 코드 없어 우리가 정함):
- ASR/HSR = learnable 스타일 벡터(d_model). 인코더 출력에 add
- fusion = residual(cr + Linear(cr+style)), zero-init → 초기엔 항등
  - ⚠️ LayerNorm 쓰면 인코더 분포 왜곡 → 생성 깨짐("의의의" 반복). residual 로 해결
- 원논문값: lr 2e-5, batch 8, λ 0.5. λ 는 0.3/0.5/0.7 비교 예정

## 4. Stage 3 DPO 구조

```
prompt   = x_ai
chosen   = x_human
rejected = SFT 가 HSR 로 생성한 것 중 RoBERTa D>τ 인 것 (hard negative)
loss     = 표준 DPO (Rafailov 2023), β=0.1
           policy=SFT본, ref=고정 SFT본
```
- trl 못 씀(StyleBART 가 커스텀) → DPO loss 직접 구현
- rejected 채점 = 게이트와 같은 RoBERTa

**전이 평가 (test 150, 사람판정율=탐지기 속인 %)**:
| 변형 | 생성품질 | 우리 D | Binoculars(독립) | 의미cos |
| --- | --- | --- | --- | --- |
| SFT | ✅ 깨끗·충실 | 87% | **63%(원본 65%와 같음)** | 0.97 |
| DPO | ❌ **반복루프 붕괴** | 100% | 98% | 0.87 |

**핵심 발견 두 개**:
1. **눈에 띄던 깨짐(띄어쓰기·URL)은 모델이 아니라 디코딩 옵션 `no_repeat_ngram_size=3` 탓.**
   한국어 정상 반복(고유명사·URL)을 금지해 garble 유발. 떼고 `repetition_penalty` 로 재생성하니
   SFT 는 깨끗·충실. (transfer_gen_fixed.jsonl / review/sft_vs_dpo_fixed.html)
2. **DPO 는 실제로 망가졌다.** no_repeat 반창고를 떼니 "출렁다리 출렁다리…" 무한 반복 붕괴.
   DPO 의 높은 전환율(100%/Binoculars 98%)은 **붕괴 텍스트가 탐지기를 헷갈린 허수**. 진짜 인간화 아님.
   → DPO 학습이 언어모델링을 무너뜨림(β=0.1 너무 낮아 SFT 에서 과이탈 추정).

**다음 세션 시작점**:
- **DPO 고치기**: β 0.1→0.3~0.5 로 올려 SFT(건강한 토대) 가까이 묶어 붕괴 없이 회피. SFT 부터 다시 쌓기.
- 생성 기본 디코딩에서 `no_repeat_ngram_size` 제거, `repetition_penalty≈1.2` 로 교체.
- SFT 는 독립 탐지기(Binoculars) 회피가 약함(63%) → 이게 진짜 과제. DPO 없이 회피할 방법 필요.
- 준비된 것: clean20k 데이터 · 동결 D · SFT/DPO 모델들(λ 0.3/0.5/0.7) · 전이평가/Stage4 스크립트.
