# 한국어 LLM 생성문의 "AI 티" 억제 연구

한국어로 쓴 글이 AI 탐지기에 어떻게 걸리는지 재고, **인간 글 ↔ AI 글 쌍(pair) 데이터셋**을 만들어
탐지기의 신뢰성을 검증한다. 이후 이 데이터로 문체 변환 모델을 학습한다.

고려대 학부 프로젝트(AIKU)이며, 방법론은 [MASH (ACL 2026 Findings)](https://aclanthology.org/)와
Russell et al. (ACL 2025)를 따른다.

## 두 트랙

| | Russell 트랙 | MASH 트랙 |
| --- | --- | --- |
| 방향 | 제목·요약을 주고 **AI가 새로 씀** | 인간 글을 **AI가 다시 씀** |
| 인간 원문 | 신문기사 100편 (국립국어원 모두의 말뭉치) | KCI 논문 초록 9,425편 |
| 현재 | 8모델 × 300건 생성 완료, 탐지기 재검증 대기 | **본 구축 진행 중** (목표 6,000쌍) |

## 주요 발견

**① 탐지기를 바꾸면 결론이 뒤집힌다.** 같은 텍스트 500건에 대해
Fast-DetectGPT는 label flip 6~14%, 카피킬러는 46~96%로 판정했다. 두 결과는 사실상 무관하다.
→ MASH가 요구한 "필터로 쓰는 탐지기 = 공격 대상 탐지기" 원칙이 실측으로 확인됐다.

**② 원문을 많이 베낄수록 AI로 안 잡힌다.** 같은 모델·같은 원문에서 프롬프트만 바꿔
12자 n그램 겹침을 16% → 49%로 벌리자 AI 판정률이 80% → 46%로 **단조 감소**했다 (피어슨 r = −0.945).
"충실하게 재서술하라"는 지시가 오히려 복사를 유도해 파이프라인을 망가뜨리고 있었다.
프롬프트는 복사율을 통해서만 작용한다.

**③ 카피킬러의 한국어 학술 초록 오탐률 13.3%** (n=150, 95% CI 8.8~19.7%).
대상은 1996~2020년, 즉 ChatGPT 이전이 확정된 인간 글이다.
무하유는 민감도만 공개하고 오탐률은 공개하지 않는다.

## 데이터는 이 저장소에 없다

인간 원문·생성 pair·탐지기 제출본은 **저작권과 약관 때문에 제외**했다
(국립국어원 모두의 말뭉치 제12조, KCI 초록 저작권, AI Hub 제3자 열람 금지).
프롬프트 파일도 마찬가지다 — 기사 제목·도입부·요약문을 원문 그대로 담기 때문이다.
데이터는 프로젝트 참여자에게만 별도 공유한다.

따라서 이 저장소만으로는 파이프라인을 재현할 수 없다. 코드와 연구 기록을 읽는 용도다.
